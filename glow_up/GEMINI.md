# GlowUp - Self-Improvement App

**Project Type**: Mobile App (Flutter)
**Framework**: Flutter (v3.29+)
**Language**: Dart
**State Management**: Riverpod
**Backend**: Supabase
**Routing**: GoRouter

## Features
1. **Auth**: Login, Signup, User Profiles.
2. **Dashboard**: Daily Quote, Navigation.
3. **Habits**: Daily tracker with streaks.
4. **Looksmaxxing**: Photo upload and analysis tips.
5. **Charisma**: Social challenges (Premium locked).
6. **Premium**: 5-day trial, Stripe integration, Feature locking.

## Setup
1. `flutter pub get`
2. Update `lib/main.dart` with your Supabase URL/Key.
3. Run SQL schema in Supabase (see `claude.md`).
4. `flutter run`
